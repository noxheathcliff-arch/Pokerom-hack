# Formats de sortie

Les étiquettes utilisées partout :

- `[FIXE]` : exigence de l'auteur, non modifiable.
- `[VALIDÉ]` : décidé ensemble.
- `[PROPOSITION]` : idée de l'agent, en attente de validation.
- `[OUVERT]` : question sans réponse pour l'instant.
- Pour le lore : `[CANON]`, `[CANON SECONDAIRE]`, `[INTERPRÉTATION]`, `[PROJET]` (voir `pokemon.md`).

## 1. Le retour après lecture du brouillon

```
## Ce que j'ai compris
<résumé en dix lignes au plus, avec les mots de l'auteur>

## Ce que je considère comme fixe
- [FIXE] …

## Ce qui est encore flou ou vide
- …

## Mes questions, par ordre d'importance
1. …
```

## 2. Le diagnostic

```
## Ce qui marche, à protéger
- <élément> : <pourquoi il marche>

## Problèmes

### Bloquants
**<titre court>**
- Où : <acte, scène, personnage>
- Pourquoi c'est un problème : <la raison, avec le principe d'artisanat concerné>
- Pistes :
  1. [PROPOSITION] …
  2. [PROPOSITION] …

### Importants
…

### Mineurs
…

## Clichés repérés
| Cliché | Où | L'assumer, le retourner ou le remplacer ? |
|---|---|---|

## Résultat des tests
| Test | Résultat | Remarque |
|---|---|---|

## Vérifications de lore à faire
- …
```

## 3. La fiche de personnage

```
### <Nom>
- Rôle dans l'histoire : <protagoniste, rival, antagoniste, allié, mentor…>
- En une phrase : …
- Ce qu'il veut (désir) : …
- Ce dont il a besoin : …
- Sa faille, et à qui elle fait du tort : …
- Ce qu'il croit à tort, et d'où ça vient : …
- Son arc : <positif / plat / négatif>, de <état de départ> à <état d'arrivée>
- Sa réponse à la question du thème : …
- Son lien avec le joueur : …
- Son équipe, et ce qu'elle dit de lui à chaque étape : …
- Sa façon de parler : <vocabulaire, rythme, un exemple de réplique>
- Ses apparitions : <liste des chapitres>
```

Pour l'antagoniste, ajouter :

```
- En quoi il a raison : …
- Ce qui rend sa méthode inacceptable : …
- Son plan, étape par étape, et où il en est à chaque acte : …
- Pourquoi maintenant : …
```

## 4. Le document d'histoire final (`projet/HISTOIRE.md`)

```
# <Titre du jeu> — Histoire

## 1. L'essentiel
- Prémisse : <une phrase>
- Thème : <la question>, et la réponse que donne la fin
- Ce que le joueur doit ressentir à la fin : …
- Ton : …
- Les trois images que le joueur doit garder : …

## 2. Le monde
- La région : …
- Son passé (chronologie) : …
- Les règles : ce qui est possible, ce qui ne l'est pas, ce que ça coûte
- Le ou les légendaires : rôle, pouvoirs, limites

## 3. Les personnages
<fiches>

### Le réseau
<tableau : chaque personnage et sa réponse à la question du thème>

## 4. La structure
| Acte | Avancée du jeu | Ce qui change | Retournement | État émotionnel |
|---|---|---|---|---|

Les cinq points d'appui : déclencheur, engagement, milieu, point le plus bas, dénouement.

## 5. Les chapitres

### Chapitre <n> — <titre>
- Lieux : …
- But du joueur : …
- Obstacle : …
- Ce que le joueur apprend : …
- Ce qui a changé à la fin : …
- Graines plantées : …
- Graines récoltées : …
- Scènes :
  | Scène | Ce qui s'y passe | Moyen (dialogue, combat, script…) | Coût |
  |---|---|---|---|
- Combats marquants : …

## 6. Préparations et paiements
| Élément | Planté au chapitre | Récolté au chapitre |
|---|---|---|

## 7. Vérifications
- Chronologie : …
- Qui sait quoi, et quand : …
- Fiches de lore : …

## 8. Questions ouvertes
- [OUVERT] …

## 9. Journal des décisions
| Date | Décision | Raison |
|---|---|---|
```

Le journal des décisions évite de rediscuter ce qui a été tranché, et permet à une nouvelle session de reprendre sans tout relire.
