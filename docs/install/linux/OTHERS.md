# Instructions générales pour les autres distributions Linux
1. Essayez d'installer les paquets suivants à l'aide de votre gestionnaire de paquets:
    - `gcc`
    - `g++`
    - `arm-none-eabi-gcc`
    - `arm-none-eabi-binutils`
    - `arm-none-eabi-newlib`
    - `make`
    - `git`
    - `libpng-dev`
    - `python3`
